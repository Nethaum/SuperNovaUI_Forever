# SuperNovaUI Forever

SuperNovaUI for World of Warcraft: Forever (Interface 16001). It is a separate addon from the Retail one
(`SuperNovaUI`), with its own saved variables, so the two never share state.

Status: the options panel (`/snui`: modules by category, enable or disable all, profile export and import) and two
features, **Macro by cooldown**, **Exploration markers**, **Elemental Convergence markers** and **Profession goal**. There are no fixes for other addons yet. A module that would be useless for you or would duplicate an addon you already run starts off; once you switch it, your choice is kept.

**Macro by cooldown** keeps one macro in step with a spell's cooldown: one text while the spell is ready, another while it
recharges, and it switches back by itself. Set it up in Tools > Macro by cooldown (spell, macro name, the two texts); the
**Fill with the druid example** button writes the racial "Sky Vision" while ready, and Cat Form plus Dash while it is on
cooldown. A macro can only change outside combat, so a change during a fight is applied when the fight ends. It does nothing
until a spell and both texts are set. For combat use, the page explains the two-fixed-macros alternative. The code is the same file as in the Retail addon (`Modules/CooldownMacro.lua`).

**Exploration markers** put a small ring, on the world map and on the minimap, on the regions of your zone that you have not discovered yet; it disappears when you discover the region. The regions come from this game's own tables (`Data/Exploration.lua`, generated by the Retail repository's `tools/gen-exploration.py`).

**Profession goal** (WoW Forever only) lets you set a target skill for any profession (for example Cooking 180, to learn a recipe that needs it). With the profession window open, a box under it shows how many points are left and the recipe that raises your skill now, using what is in your bags. No recipe or item is written in the addon: names come from the game, in your language. Type only the name of the recipe and the level is found for you, from a list of the WoW Forever recipes that is built into the addon. That list comes from the data of [VoidProf](https://www.curseforge.com/wow/addons/voidprof) (bughatti, MIT; notice in `SuperNovaUI_Forever/THIRD_PARTY_NOTICES.md`); no other addon has to be installed for it.

The goal also gets **the cheapest way to reach it**: from your skill to the goal, each craft is the recipe with the lowest price per expected skill point, and recipes sold as books are counted with their price. Prices come from the Auction House through Auctionator (or TradeSkillMaster) when installed, and from vendors: the list of [VoidGPS](https://www.curseforge.com/wow/addons/voidgps) (bughatti, GPL-3.0) when it is installed, read through its public `VoidGPS.Goods:Get` so nothing of it is copied into this addon (no vendor has to be opened), or else the vendors the addon has seen you visit; an item with no price from those is shown as "price unknown", never guessed. `/snui goal plan` prints the steps and what to buy.

**Elemental Convergence markers** (WoW Forever only) mark every elemental convergence on the world map and on the minimap with a small wind swirl, for the Skysight of the Windshaper Skyborne. It starts on only for that race and off for everyone else. The positions are in `Data/Convergence.lua`, taken from the Wowhead page of the object (the game does not hold them). If the addon [Skyborne Leyline & Convergence Marker](https://www.curseforge.com/wow/addons/sllcm) (tr0tsky, MIT) is installed, its bigger and growing list is used instead (it offers it through `SLLCM_GetNodes`); since that addon draws the same markers, this module starts off next to it.

## Install

Copy both folders to `World of Warcraft/_forever_/Interface/AddOns/`:

- `SuperNovaUI_Forever/` - the addon.
- `!SuperNovaUI_Forever_Compat/` - loads first; will restore API functions the game lacks (empty for now).

## Commands

- `/snui` - open the options panel.
- `/snui status` - show the modules and whether they are enabled.
- `/snui macro` - show the state of the macro by cooldown.
- `/snui explore` - list the regions of the current zone that are still undiscovered.
- `/snui converge` - how many elemental convergences the current zone has.
- `/snui goal` - how far the goal of the open profession is.
- `/snui goal plan` - the cheapest way to it, with prices and what to buy.
- `/snui reload` - reload the UI.

## Layout

- `SuperNovaUI_Forever/Core/` - bootstrap, database, console, slash commands.
- `SuperNovaUI_Forever/Modules/Forever/` - the WoW Forever page (no fixes yet).
- `SuperNovaUI_Forever/Modules/CooldownMacro.lua` - Macro by cooldown (shared with Retail).
- `SuperNovaUI_Forever/Modules/Exploration.lua` - Exploration markers (shared with Retail); `Data/Exploration.lua` is generated for this client.
- `SuperNovaUI_Forever/Modules/Goal*.lua` - Profession goal (shared with the Retail addon, edited there), one small file per job: `GoalStore` (saved data), `GoalGame` (what the game says), `GoalRecipes` (recipe levels), `GoalPage` (settings page), `GoalReport` (summary and texts), `Goals` (box, events, command, registration); `Data/Recipes.lua` is the recipe list, made by `tools/gen-recipes.py` from VoidProf's data; `Modules/Forever/GoalPlan.lua` is the price and plan maths.
- `SuperNovaUI_Forever/Modules/Forever/Convergence.lua` - Elemental Convergence markers (this addon only); `Data/Convergence.lua` holds the positions.
- Each `.toc` exists twice (plain and `_Camelot`) because the client picks one by suffix; keep them identical.

Build the zip with `python build/package.py` (writes `dist/SuperNovaUI-Forever-<version>.zip`).

The Retail addon lives in its own repository folder: `SuperNovaUI`. MIT license.
